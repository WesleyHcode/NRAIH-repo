# SourceSort

A way to search, reference, and check sources through a background analysis.  
Available features I'm thinking of inplementing:  
- AI can determine if a source supports Radical, Liberal, Conservative, or Reactionary viewpoints
- Author or organization's previous reporting
- Comparison between different sources
- Auto citing feature

Dangers:  
AI could mistake sourcing or make bogus analysis.
